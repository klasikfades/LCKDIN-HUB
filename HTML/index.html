        Setting up a new table

        1. Name the cardUse the room and table, like Focus table 1. Walk-ins show as "Focus table 1 : guest name".
        2. Pick the categoryThe room's rate card is used for billing. A pass category makes a pass card.
        3. Create and copy the linkEach card gets its own token and tap link.
        4. Write it to the tagIn NFC Tools: Write, Add a record, URL, paste the link, then tap the tag.
        5. Test itTap the tag with a phone. It should open the check-in screen for that table.
